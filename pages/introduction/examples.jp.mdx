## テキストの要約

自然言語生成における標準タスクの 1 つは、テキストの要約です。テキストの要約には、さまざまなフレーバーやドメインを含めることができます。実際、言語モデルの最も有望なアプリケーションの 1 つは、記事や概念を素早く読みやすい概要に要約する機能です。プロンプトを使用した基本的な要約タスクを試してみましょう。

抗生物質について知りたいと思ったら、次のようなプロンプトを試してみるとよいでしょう。

*プロンプト：*

```
Explain antibiotics

A:
```

*出力：*

```
Antibiotics are a type of medication used to treat bacterial infections. They work by either killing the bacteria or preventing them from reproducing, allowing the body’s immune system to fight off the infection. Antibiotics are usually taken orally in the form of pills, capsules, or liquid solutions, or sometimes administered intravenously. They are not effective against viral infections, and using them inappropriately can lead to antibiotic resistance.
```

「A:」は、質問応答で使用する明示的なプロンプト形式です。ここではこれを使用して、さらに期待される答えがあることをモデルに伝えました。この例では、これがどのように役立つのか、使用しないのかは明確ではありませんが、それは後の例のために残しておきます。これでは情報が多すぎるため、さらに要約したいと考えてみましょう。実際、次のようにモデルに 1 つの文に要約するように指示できます。

*プロンプト：*

```
Antibiotics are a type of medication used to treat bacterial infections. They work by either killing the bacteria or preventing them from reproducing, allowing the body’s immune system to fight off the infection. Antibiotics are usually taken orally in the form of pills, capsules, or liquid solutions, or sometimes administered intravenously. They are not effective against viral infections, and using them inappropriately can lead to antibiotic resistance.

Explain the above in one sentence:
```

*出力：*

```
Antibiotics are medications used to treat bacterial infections by either killing the bacteria or stopping them from reproducing, but they are not effective against viruses and overuse can lead to antibiotic resistance.
```

上記の出力の精度にはあまり注意を払わずに (これについては後のガイドで触れます)、モデルは段落を 1 つの文に要約しようとしました。手順を読めば賢くなれますが、それについては後の章に残しておきます。ここで一時停止して、より良い結果が得られるかどうかを試してみてください。

## 情報抽出

言語モデルは、自然言語生成と関連タスクを実行するようにトレーニングされていますが、分類やその他のさまざまな自然言語処理 (NLP) タスクを実行することもできます。

以下は、特定の段落から情報を抽出するプロンプトの例です。

*プロンプト：*

```
Author-contribution statements and acknowledgements in research papers should state clearly and specifically whether, and to what extent, the authors used AI technologies such as ChatGPT in the preparation of their manuscript and analysis. They should also indicate which LLMs were used. This will alert editors and reviewers to scrutinize manuscripts more carefully for potential biases, inaccuracies and improper source crediting. Likewise, scientific journals should be transparent about their use of LLMs, for example when selecting submitted manuscripts.

Mention the large language model based product mentioned in the paragraph above:
```

*出力：*

```
The large language model based product mentioned in the paragraph above is ChatGPT.
```

上記の結果を改善する方法はたくさんありますが、これはすでに非常に便利です。

ここまでで、モデルに何をすべきかを指示するだけで、モデルにさまざまなタスクの実行を依頼できることが明らかになったはずです。これは、AI 製品開発者がすでに強力な製品やエクスペリエンスを構築するために使用している強力な機能です。

段落ソース:[ChatGPT: 研究の 5 つの優先事項](https://www.nature.com/articles/d41586-023-00288-7)

## 質問への回答

モデルに特定の回答を返させるための最良の方法の 1 つは、プロンプトの形式を改善することです。前に説明したように、プロンプトは命令、コンテキスト、入力、出力インジケーターを組み合わせて結果を改善できます。これらのコンポーネントは必須ではありませんが、指示がより具体的であればあるほど、より良い結果が得られるため、これは良い習慣になります。以下は、より構造化されたプロンプトの後にこれがどのように表示されるかを示す例です。

*プロンプト：*

```
Answer the question based on the context below. Keep the answer short and concise. Respond "Unsure about answer" if not sure about the answer.

Context: Teplizumab traces its roots to a New Jersey drug company called Ortho Pharmaceutical. There, scientists generated an early version of the antibody, dubbed OKT3. Originally sourced from mice, the molecule was able to bind to the surface of T cells and limit their cell-killing potential. In 1986, it was approved to help prevent organ rejection after kidney transplants, making it the first therapeutic antibody allowed for human use.

Question: What was OKT3 originally sourced from?

Answer:
```

*出力：*

```
Mice.
```

から取得したコンテキスト[自然](https://www.nature.com/articles/d41586-023-00400-x).

## テキストの分類

ここまでは、簡単な指示を使用してタスクを実行してきました。迅速なエンジニアとして、より適切な指示を提供できるようになる必要があります。しかしそれだけではありません！また、より難しいユースケースでは、手順を提供するだけでは十分ではないこともわかります。ここでは、コンテキストとプロンプトで使用できるさまざまな要素についてさらに考える必要があります。提供できるその他の要素は次のとおりです。`input data` or `examples`.

テキスト分類の例を示してこれを実証してみましょう。

*プロンプト：*

```
Classify the text into neutral, negative or positive. 

Text: I think the food was okay. 
Sentiment:
```

*出力：*

```
Neutral
```

テキストを分類するように指示すると、モデルは次のように応答しました。`'Neutral'`、それは正しいです。これには何も問題はありませんが、本当に必要なのは、モデルが希望どおりの形式でラベルを提供することだとしましょう。だから代わりに`Neutral`、返してほしいですよね`neutral`。どうやってこれを達成しますか?これにはさまざまな方法があります。ここでは具体性を重視するため、プロンプトに提供できる情報が多いほど、より良い結果が得られます。正しい動作を指定するための例を提供してみることができます。もう一度試してみましょう:

*プロンプト：*

```
Classify the text into neutral, negative or positive. 

Text: I think the vacation is okay.
Sentiment: neutral 

Text: I think the food was okay. 
Sentiment:
```

*出力：*

```
neutral
```

完璧！今回モデルが戻ってきました`neutral`これはあなたが探していた特定のラベルです。プロンプトで提供された例は、モデルの出力を具体化するのに役立ったようです。

時には具体的であることが重要である理由を強調するには、以下の例を確認して問題を見つけてください。

*プロンプト：*

```
Classify the text into nutral, negative or positive. 

Text: I think the vacation is okay.
Sentiment:
```

*出力：*

```
Neutral
```

ここで何が問題になっているのでしょうか？ヒントとしては、`nutral`label はモデルによって完全に無視されます。代わりに、モデルは次のように出力します。`Neutral`そのラベルに対する偏見があるからです。しかし、あなたが本当に望んでいることは`nutral`。これをどうやって修正しますか?ラベルに説明を追加したり、プロンプトに例を追加したりしてみてはいかがでしょうか。よくわからない場合は、次のセクションでいくつかのアイデアについて説明します。

## 会話

おそらく、プロンプト エンジニアリングで達成できる最も興味深いことの 1 つは、LLM システムに動作方法、その意図、およびそのアイデンティティを指示することです。これは、カスタマー サービス チャットボットなどの会話システムを構築する場合に特に役立ちます。

たとえば、質問に対してより技術的かつ科学的な応答を生成できる会話システムを作成してみましょう。命令を通じてどのように動作するかを明示的に指示していることに注意してください。これは、次のように呼ばれることもあります*役割のプロンプト*.

*プロンプト：*

```
The following is a conversation with an AI research assistant. The assistant tone is technical and scientific.

Human: Hello, who are you?
AI: Greeting! I am an AI research assistant. How can I help you today?
Human: Can you tell me about the creation of blackholes?
AI:
```

*出力：*

```
Sure! Black holes are regions of spacetime where the gravitational force is so strong that nothing, not even light, can escape from it. They are created when a very massive star dies and its core collapses in on itself, forming a singularity of infinite density. The intense gravity of the singularity pulls in all the matter and radiation around it, creating the black hole.
```

AI 研究アシスタントというと、少し専門的すぎるように思えますよね?さて、この動作を変更して、よりアクセスしやすい回答を提供するようにシステムに指示しましょう。

*プロンプト：*

```
The following is a conversation with an AI research assistant. The assistant answers should be easy to understand even by primary school students.

Human: Hello, who are you?
AI: Greeting! I am an AI research assistant. How can I help you today?
Human: Can you tell me about the creation of black holes?
AI: 
```

*出力：*

```
Sure! Black holes are created when a very massive star runs out of fuel and collapses in on itself. The gravity of the star is so strong that nothing, not even light, can escape its pull. This creates a point in space-time with an intense gravitational force called a black hole.
```

ある程度の進歩はありましたね。改善を続けることができます。さらに例を追加すると、さらに良い結果が得られる可能性があります。

## コード生成

LLM が非常に効果的なアプリケーションの 1 つはコード生成です。副操縦士はその好例です。賢いプロンプトを使用して実行できるコード生成タスクは数多くあります。以下にいくつかの例を見てみましょう。

まず、ユーザーを迎える簡単なプログラムを試してみましょう。

*プロンプト：*

```
/*
Ask the user for their name and say "Hello"
*/
```

*出力：*

```
let name = prompt("What is your name?");
console.log(`Hello, ${name}!`);
```

使用する言語を指定する必要さえなかったことに注目してください。

少しレベルを切り替えてみましょう。以下の例は、プロンプトの設計にもう少し努力することで LLM がどれほど強力になるかを示しています。

*プロンプト：*

```
"""
Table departments, columns = [DepartmentId, DepartmentName]
Table students, columns = [DepartmentId, StudentId, StudentName]
Create a MySQL query for all students in the Computer Science Department
"""
```

*出力：*

```
SELECT StudentId, StudentName 
FROM students 
WHERE DepartmentId IN (SELECT DepartmentId FROM departments WHERE DepartmentName = 'Computer Science');
```

これはとても印象的です。この場合、データベース スキーマに関するデータを提供し、有効な MySQL クエリを生成するように依頼しました。

## 推論

おそらく、今日の LLM にとって最も困難なタスクの 1 つは、何らかの推論を必要とするタスクです。推論は、LLM から出現する可能性のある複雑なアプリケーションの種類により、最も興味深い分野の 1 つです。

数学的能力を伴うタスクがいくつか改善されました。そうは言っても、現在の LLM は推論タスクを実行するのに苦労しているため、これにはさらに高度なプロンプト エンジニアリング技術が必要であることに注意することが重要です。これらの高度なテクニックについては、次のガイドで説明します。ここでは、算術機能を示すためにいくつかの基本的な例を取り上げます。

*プロンプト：*

```
What is 9,000 * 9,000?
```

*出力：*

```
81,000,000
```

もっと難しいことに挑戦しましょう。

*プロンプト：*

```
The odd numbers in this group add up to an even number: 15, 32, 5, 13, 82, 7, 1. 

A: 
```

*出力*

```
No, the odd numbers in this group add up to an odd number: 119.
```

それは間違いです!プロンプトを改善してこれを改善してみましょう。

*プロンプト：*

```
The odd numbers in this group add up to an even number: 15, 32, 5, 13, 82, 7, 1. 

Solve by breaking the problem into steps. First, identify the odd numbers, add them, and indicate whether the result is odd or even. 
```

*出力：*

```
Odd numbers: 15, 5, 13, 7, 1
Sum: 41 
41 is an odd number.
```

ずっと良いですよね？ちなみに、このタスクを数回試しましたが、モデルは時々失敗します。例と組み合わせてより適切な手順を提供すると、より正確な結果が得られる可能性があります。
