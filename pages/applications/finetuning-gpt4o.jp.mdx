# GPT-4o モデルによる微調整

import { Callout } from 'nextra/components'

OpenAI recently [発表された](https://openai.com/index/gpt-4o-fine-tuning/)最新モデルの GPT-4o および GPT-4o mini の微調整が可能です。この新機能により、開発者は特定のユースケースに合わせて GPT-4o モデルをカスタマイズし、パフォーマンスを強化し、出力を調整することができます。

## 詳細とコストの微調整

開発者は、`GPT-4o-2024-08-06`専用ツールによる微調整のチェックポイント[ダッシュボードの微調整](https://platform.openai.com/finetune)。このプロセスにより、応答構造、トーン、および複雑なドメイン固有の指示の遵守をカスタマイズできます。

GPT-4o の微調整にかかるコストは、トレーニングの場合は 100 万トークンあたり 25 ドル、推論の場合は入力トークン 100 万あたり 3.75 ドル、出力トークン 100 万あたり 15 ドルです。この機能は、有料使用レベルの開発者のみが利用できます。

## 実験用の無料トレーニング トークン

この新機能の探索を促進するために、OpenAI は 9 月 23 日までの期間限定プロモーションを提供します。  開発者は、GPT-4o の場合は 1 日あたり 100 万の無料トレーニング トークン、GPT-4o mini の場合は 1 日あたり 200 万の無料トレーニング トークンにアクセスできます。これは、微調整されたモデルの革新的なアプリケーションを実験して発見する良い機会となります。

## 微調整されたモデルへのアクセスと評価

微調整プロセスが完了すると、開発者は OpenAI プレイグラウンドを通じてカスタム モデルにアクセスして評価できるようになります。プレイグラウンドでは、さまざまな入力を使用したインタラクティブなテストが可能になり、モデルのパフォーマンスについての洞察が得られます。より包括的な評価を行うために、開発者は OpenAI API を介して微調整されたモデルをアプリケーションに統合し、体系的なテストを実施できます。

OpenAI による GPT-4o モデルの微調整の導入により、特殊なタスクに LLM の力を活用しようとしている開発者に新たな可能性が開かれます。
