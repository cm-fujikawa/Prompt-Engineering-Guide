# エージェントのコンポーネント

import { Callout } from 'nextra/components'

AI エージェントには、複雑なタスクに効果的に取り組むために、計画能力、ツールの利用、メモリ管理という 3 つの基本的な能力が必要です。これらのコンポーネントがどのように連携して機能する AI エージェントを作成するかについて詳しく見てみましょう。

![Agent Components](../../img/agents/agent-components.png)

## 計画: エージェントの頭脳

効果的な AI エージェントの中核となるのは、大規模言語モデル (LLM) を活用した計画機能です。最新の LLM により、いくつかの重要な計画機能が可能になります。

- 思考連鎖推論によるタスクの分解
- 過去の行動や情報を振り返る
- 将来の意思決定を改善するための適応学習
- 現在の進捗状況の批判的分析

現在の LLM 計画機能は完璧ではありませんが、タスクを完了するには不可欠です。堅牢な計画能力がなければ、エージェントは複雑なタスクを効果的に自動化できず、その本来の目的が果たせなくなります。

## ツールの活用: エージェントの能力を拡張する

2 番目の重要なコンポーネントは、エージェントが外部ツールと連携できる機能です。適切に設計されたエージェントは、さまざまなツールにアクセスできるだけでなく、それらをいつ、どのように適切に使用するかを理解する必要があります。一般的なツールには次のものがあります。

- コードインタープリタと実行環境
- Web 検索およびスクレイピング ユーティリティ
- 数学計算機
- 画像生成システム

これらのツールを使用すると、エージェントは計画されたアクションを実行し、抽象的な戦略を具体的な結果に変えることができます。ツールの選択とタイミングを理解する LLM の能力は、複雑なタスクを効果的に処理するために重要です。

## 記憶システム: 情報の保持と利用

3 番目の重要なコンポーネントはメモリ管理です。メモリ管理には、次の 2 つの主な形式があります。

1. 短期（作業）記憶
   - 直接のコンテキストのバッファとして機能します。
   - コンテキストに沿った学習を可能にする
   - ほとんどのタスクを完了するには十分です
   - タスクの反復中に継続性を維持するのに役立ちます

2. 長期記憶
   - 外部ベクター ストアを通じて実装
   - 履歴情報の迅速な取得を可能にします
   - 将来のタスクの完了に役立ちます
   - あまり一般的には実装されていないが、将来の開発にとって重要になる可能性がある

メモリ システムを使用すると、エージェントは外部ツールから収集した情報を保存および取得できるため、反復的な改善と以前の知識に基づく構築が可能になります。

計画機能、ツールの利用、記憶システムの間の相乗効果が、効果的な AI エージェントの基盤を形成します。各コンポーネントには現在の制限がありますが、AI エージェントを開発して操作するには、これらのコア機能を理解することが重要です。テクノロジーが進化するにつれて、新しいメモリの種類や機能が登場する可能性がありますが、これら 3 つの柱は AI エージェント アーキテクチャの基礎であり続けるでしょう。
