# プロンプトエンジニアリングガイド

import { Callout } from 'nextra/components'

プロンプト エンジニアリングは、さまざまなアプリケーションや研究トピックに対して言語モデル (LM) を効率的に使用するためのプロンプトを開発および最適化するための比較的新しい分野です。迅速なエンジニアリング スキルは、大規模言語モデル (LLM) の機能と制限をより深く理解するのに役立ちます。

研究者は、プロンプト エンジニアリングを使用して、質問応答や算術推論などの一般的で複雑なタスクの広範囲にわたる LLM の能力を向上させています。開発者はプロンプト エンジニアリングを使用して、LLM やその他のツールと連携する堅牢で効果的なプロンプト手法を設計します。

プロンプト エンジニアリングは、プロンプトを設計および開発することだけを意味するものではありません。これには、LLM とのやり取りや開発に役立つ幅広いスキルとテクニックが含まれています。これは、LLM のインターフェイス、構築、および LLM の機能を理解するための重要なスキルです。プロンプト エンジニアリングを使用して LLM の安全性を向上させ、ドメイン知識や外部ツールで LLM を強化するなどの新しい機能を構築できます。

LLM を使用した開発に対する高い関心を動機として、最新の論文、高度なプロンプト手法、学習ガイド、モデル固有のプロンプト ガイド、講義、参考資料、新しい LLM 機能、およびプロンプト エンジニアリングに関連するツールをすべて含む、この新しいプロンプト エンジニアリング ガイドを作成しました。
