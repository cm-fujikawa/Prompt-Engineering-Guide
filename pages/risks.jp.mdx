適切に作成されたプロンプトは、少数ショット学習や思考連鎖プロンプトなどのテクニックを使用して、さまざまなタスクで LLM を効果的に使用することにつながります。 LLM 上に現実世界のアプリケーションを構築することを考えるとき、言語モデルに関連する誤用、リスク、安全対策について考えることも重要になります。

このセクションでは、プロンプト インジェクションなどの手法による LLM のリスクと誤用の一部に焦点を当てます。また、有害な行為と、効果的なプロンプト手法やモデレーション API などのツールを使用してそれらを軽減する方法についても強調します。その他の興味深いトピックには、一般化可能性、調整、偏見、社会的偏見、事実性などが含まれます。
