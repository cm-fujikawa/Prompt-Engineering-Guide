## プロンプトチェーンの概要

<iframe width="100%" height="415px" src="https://www.youtube.com/embed/CKZC5RigYEc?si=EG1kHf83ceawWdHX" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen />

LLM の信頼性とパフォーマンスを向上させるための重要なプロンプト エンジニアリング手法の 1 つは、タスクをサブタスクに分割することです。これらのサブタスクが識別されると、LLM にサブタスクのプロンプトが表示され、その応答が別のプロンプトへの入力として使用されます。これはプロンプト チェーンと呼ばれるもので、プロンプト操作のチェーンを作成するという目的でタスクがサブタスクに分割されます。

プロンプト チェーンは、非常に詳細なプロンプトでプロンプトが表示された場合に LLM が対処するのに苦労する可能性がある複雑なタスクを実行するのに役立ちます。プロンプト チェーンでは、チェーン プロンプトは、最終的な望ましい状態に到達する前に、生成された応答に対して変換または追加のプロセスを実行します。

プロンプト チェーニングは、パフォーマンスの向上に加えて、LLM アプリケーションの透明性を高め、制御性と信頼性を向上させるのに役立ちます。これは、モデル応答に関する問題をより簡単にデバッグし、改善が必要なさまざまな段階でパフォーマンスを分析して改善できることを意味します。

プロンプト チェーンは、LLM を利用した会話アシスタントを構築し、アプリケーションのパーソナライゼーションとユーザー エクスペリエンスを向上させる場合に特に役立ちます。

## プロンプトチェーンの使用例

### ドキュメント QA のプロンプト チェーン

プロンプト チェーンは、複数の操作や変換を伴う可能性のあるさまざまなシナリオで使用できます。たとえば、LLM の一般的な使用例には、大きなテキスト ドキュメントに関する質問に答えることが含まれます。これは、2 つの異なるプロンプトを設計し、最初のプロンプトが質問に答えるために関連する引用を抽出する役割を果たし、2 番目のプロンプトが特定の質問に答えるための引用と元の文書を入力として受け取る場合に役立ちます。つまり、文書内で与えられた質問に答えるタスクを実行するための 2 つの異なるプロンプトを作成することになります。

以下の最初のプロンプトは、質問が与えられた文書から関連する引用を抽出します。わかりやすくするために、ドキュメントのプレースホルダーを追加していることに注意してください。`{{document}}`。プロンプトをテストするには、このページなどの Wikipedia の記事をコピーして貼り付けます。[プロンプトエンジニアリング](https://en.wikipedia.org/wiki/Prompt_engineering)。このタスクではより大きなコンテキストが使用されるため、`gpt-4-1106-preview`OpenAI のモデル。このプロンプトは、Claude などの他のロングコンテキスト LLM で使用できます。

プロンプト 1:

```
You are a helpful assistant. Your task is to help answer a question given in a document. The first step is to extract quotes relevant to the question from the document, delimited by ####. Please output the list of quotes using <quotes></quotes>. Respond with "No relevant quotes found!" if no relevant quotes were found.


####
{{document}}
####
```

これは、`user`役割。

プロンプト 1 の出力:

```
<quotes>
- Chain-of-thought (CoT) prompting[27]
- Generated knowledge prompting[37]
- Least-to-most prompting[38]
- Self-consistency decoding[39]
- Complexity-based prompting[41]
- Self-refine[42]
- Tree-of-thought prompting[43]
- Maieutic prompting[45]
- Directional-stimulus prompting[46]
- Textual inversion and embeddings[59]
- Using gradient descent to search for prompts[61][62][63][64]
- Prompt injection[65][66][67]
</quotes>
```

最初のプロンプトで返された引用符は、以下の 2 番目のプロンプトへの入力として使用できるようになりました。引用をもう少しクリーンアップする、つまり引用を削除することができることに注意してください。これらの引用は削除することも、チェーン内の別のプロンプトの一部として利用することもできますが、今のところは無視してかまいません。次に、2 番目のプロンプトは、プロンプト 1 で抽出された関連する引用符を取得し、文書内で指定された質問と抽出された引用符に対する有用な応答を準備します。 2 番目のプロンプトは次のようになります。

プロンプト 2:

```
Given a set of relevant quotes (delimited by <quotes></quotes>) extracted from a document and the original document (delimited by ####), please compose an answer to the question. Ensure that the answer is accurate, has a friendly tone, and sounds helpful.

####
{{document}}
####

<quotes>
- Chain-of-thought (CoT) prompting[27]
- Generated knowledge prompting[37]
- Least-to-most prompting[38]
- Self-consistency decoding[39]
- Complexity-based prompting[41]
- Self-refine[42]
- Tree-of-thought prompting[43]
- Maieutic prompting[45]
- Directional-stimulus prompting[46]
- Textual inversion and embeddings[59]
- Using gradient descent to search for prompts[61][62][63][64]
- Prompt injection[65][66][67]
</quotes>
```

プロンプト 2 の出力:

```
The prompting techniques mentioned in the document include:

1. Chain-of-thought (CoT) prompting[27]
2. Generated knowledge prompting[37]
3. Least-to-most prompting[38]
4. Self-consistency decoding[39]
5. Complexity-based prompting[41]
6. Self-refine[42]
7. Tree-of-thought prompting[43]
8. Maieutic prompting[45]
9. Directional-stimulus prompting[46]
10. Textual inversion and embeddings[59]
11. Using gradient descent to search for prompts[61][62][63][64]
12. Prompt injection[65][66][67]

Each of these techniques employs unique strategies to enhance or specify the interactions with large language models to produce the desired outcomes.
```

ご覧のとおり、プロンプト チェーンを簡略化して作成することは、応答にいくつかの操作や変換が必要な場合に便利なプロンプト アプローチです。演習として、アプリケーションのユーザーに最終応答として送信する前に、応答から引用 (例: \[27]) を削除するプロンプトを自由に設計してください。
