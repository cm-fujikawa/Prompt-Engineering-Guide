# Active-Prompt

思考連鎖 (CoT) メソッドは、人間が注釈を付けたサンプルの固定セットに依存します。これに関する問題は、模範がさまざまなタスクにとって最も効果的な例ではない可能性があることです。これに対処するには、[Diao et al., (2023)](https://arxiv.org/pdf/2302.12246.pdf)最近、LLM をさまざまなタスク固有のプロンプト例に適応させるための、Active-Prompt と呼ばれる新しいプロンプト アプローチを提案しました (人間が設計した CoT 推論で注釈が付けられています)。

以下にアプローチの図を示します。最初のステップは、いくつかの CoT サンプルを使用して、または使用せずに LLM をクエリすることです。*k*一連のトレーニング質問に対して考えられる回答が生成されます。不確実性メトリックは、以下に基づいて計算されます。*k*回答（意見の相違は使用されます）。最も不確かな質問は、人間が注釈を付けるために選択されます。新しい注釈付きのサンプルは、各質問を推測するために使用されます。
