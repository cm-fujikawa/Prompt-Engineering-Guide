## OpenAI 4o イメージ生成ガイド

4o 画像生成モデルの使用に関する実践的なガイド

![A stylized title in front of an OpenAI logo, behind frosted glass.](../../img/4o-image-generation/4o_image_generation.png)

### 4o 画像生成モデルとは何ですか?

4o Image Generation は、ChatGPT に埋め込まれた OpenAI の最新の画像モデルです。フォトリアリスティックな出力を作成し、画像を入力として取得して変換し、テキストを画像に生成するなどの詳細な指示に従うことができます。 OpenAI は、モデルが自己回帰的であり、GPT-4o LLM と同じアーキテクチャを使用していることを確認しました。モデルは基本的に、LLM がテキストを生成するのと同じ方法で画像を生成します。これにより、画像の上にテキストをレンダリングしたり、より詳細な画像編集を行ったり、画像入力に基づいて画像を編集したりする機能が向上します。

### 4o 画像生成へのアクセス方法

ChatGPT アプリケーション (Web またはモバイル) の画像生成にアクセスするには、テキストでプロンプトを表示するか、ツールから「画像の作成」を選択します。このモデルには、Sora または gpt-image-1 を使用した OpenAI API 経由でもアクセスできます。

プロンプトのテキスト: 「…の画像を生成します」![text\_prompt](../../img/4o-image-generation/text_prompt_3.JPG)

ツールボックスから「イメージの作成」を選択します。![tool\_select](../../img/4o-image-generation/tool_select.JPG)

With the OpenAI API [OpenAI API](https://platform.openai.com/docs/guides/images-vision?api-mode=responses).
![Screenshot of the OpenAI API documentation page](../../img/4o-image-generation/image_gen_API.JPG)

**4o イメージ生成には、次のモデルでアクセスできます。**

- gpt-4o
- gpt-4o-mini
- gpt-4.1
- gpt-4.1-mini
- gpt-4.1-nano
- o3

### 4o 画像生成モデルでは何ができるのでしょうか?

**次のアスペクト比で画像を作成します。**

- 正方形 1:1 1024x1024 (デフォルト)
- 風景 3:2 1536x1024
- ポートレート 2:3 1024x1536

**ファイル タイプで参照画像を使用します。**

- PNG
- JPEG
- WEBP
- Non-animated GIF

**画像を編集するには:**

**修復**(そのチャットで生成された画像のみ)![Example of inpainting.](../../img/4o-image-generation/inpainting_combined.png)

### 4o 画像生成に関するヒント

#### 詳細なプロンプトにより、より詳細な制御が可能になります。

プロンプトが説明的でない場合、ChatGPT は多くの場合、追加の詳細を入力します。これは簡単なテストや調査には役立ちますが、何か具体的なことを念頭に置いている場合は、詳細で説明的なプロンプトを作成してください。

<Callout type="info" emoji="💡">
説明に苦労している場合は、o3 に、独自の説明に基づいて 4o 画像生成用に最適化された 3 つのさまざまなプロンプトを書いてもらい、詳細を記入してもらいます。次に、最も気に入った部分を選択し、それをプロンプトとして使用します。
</Callout>

#### 照明、構成、スタイル

特定の目標がある場合は、プロンプトでこれらを定義します。このモデルは、プロンプト内の一般的な情報に基づいてそれらを推定するのに非常に優れていますが、特定の結果が必要な場合は、それらを正確に定義する必要があります。画像を特定のカメラとレンズの種類で撮影した写真に似せたい場合は、それをプロンプトに追加します。

考慮すべきその他の詳細:

- 主題
- 中くらい
- 環境
- 色
- 気分

#### さまざまな画像生成タスクにはさまざまなモデルを選択してください

4o は、1 回限りの編集または単純なイメージ生成タスクでは最速です。

世代が複数のステップを踏むことが予想される場合は、推論モデルを使用します。創造的な探索を行うときに要素の追加または削除を繰り返し行う場合、推論モデルは、画像の一貫した要素を「念頭に置いて」より適切に機能します。たとえば、画像には特定のスタイル、フォント、色などが必要です。例は次のとおりです。[サムネイル作成プロセスへのリンク](https://chatgpt.com/share/68404206-5710-8007-8262-6efaba15a852).

#### 画像のアスペクト比

参照画像を使用する場合でも、プロンプトで必要なアスペクト比を指定するのに役立ちます。モデルは、プロンプトに手がかりがある場合は正しいアスペクト比を選択できますが (例、ロケットの画像は 2:3 であることが多い)、特に指示がない場合はデフォルトで 1:1 になります。

*テストのプロンプト:*

```
A high-resolution photograph of a majestic Art Deco-style rocket inspired by the scale and grandeur of the SpaceX Starship, standing on a realistic launch pad during golden hour. The rocket has monumental vertical lines, stepped geometric ridges like the American Radiator Building, and a mirror-polished metallic surface reflecting a vivid sunset sky. The rocket is photorealistic, awe-inspiring, and elegant, bathed in cinematic warm light with strong shadows and a vast landscape stretching to the horizon.
```

![A photorealistic, Art Deco-style rocket on a launchpad at sunset, generated from the provided test prompt.](../../img/4o-image-generation/art_deco_starship.png)

#### モデルの世代間の一貫性を意識する

これは、画像の細部を変更したい場合には適していますが、よりクリエイティブになりたい場合には困難です。モデルは、同じチャットで生成された画像を「記憶」します。独立したさまざまな画像生成タスクの場合は、毎回新しいチャットで新たに開始することをお勧めします。

<Callout type="info" emoji="💡">
画像の最初の数回の反復が意図したものにさえ及ばない場合は、**イメージの生成に使用されたプロンプトを出力するようにモデルに依頼します。**, そして、強調の位置が間違っているかどうかを確認してください。次に、新しいチャットを開始し、修正されたプロンプトで生成を続けます。
</Callout>

#### 1 つのプロンプトで複数のイメージを生成する

o3 や o4-mini などの推論モデルは、1 つのプロンプトで複数のイメージを生成できますが、これはプロンプトで明示的に指定する必要があり、常に機能するとは限りません。例：[チャットリンク](https://chatgpt.com/share/68496cf8-0120-8007-b95f-25a940298c09)

*テストのプロンプト:*

```
Generate an image of [decide this yourself], in the style of an oil painting by Van Gogh. Use a 3:2 aspect ratio. Before you generate the image, recite the rules of this image generation task. Then send the prompt to the 4o Image Generation model. Do not use DALL-E 3. If the 4o Image Generation model is timed out, tell me how much time is left until you can queue the next prompt to the model.

Rules:
- Use only the aspect ratio mentioned earlier.
- Output the prompt you sent to the image generation model exactly as you sent it, do this every time in between image generations
- Create three variations with a different subject, but the same rules. After an image is generated, immediately start creating the next one, without ending your turn or asking me for confirmation for moving forward.
```

#### 即時遵守の徹底は困難

複数のコンポーネントを含むプロンプトは、チャット モデルと 4o 画像生成モデルの間のどこかで変更されることがあります。同じチャット内で複数の画像を生成した場合、プロンプトで変更を行ったにもかかわらず、以前に生成した画像が出力に影響を与える可能性があります。

### 制限事項

- ChatGPT は、イメージ生成モデルに送信される前に、最初のプロンプトを変更できます。これは、プロンプトに説明がない場合、または長いプロンプトを使用している場合、複数ターンの生成タスクで発生する可能性が高くなります。
- ユーザーまたはサブスクリプションあたりの生成量がどのくらいになるかは明らかではありません。 OpenAI は、システムは動的であるため、サブスクリプションと地域のサーバー負荷に依存する可能性があると述べています。
- 無料枠の世代はキューに入れられることが多く、生成に時間がかかることがあります。
- 生成された画像は黄色がかった色になる場合があります。
- プロンプト画像または参照画像に暗い要素が含まれている場合、生成された画像が暗すぎる可能性があります。
- 生成の拒否: 画像の生成には、OpenAI の他のサービスと同じ一般ルールが適用されます。[使用ポリシー](https://openai.com/policies/usage-policies/)。プロンプト、参照画像、または生成された出力画像内で禁止された主題が検出された場合、多くの場合、生成は拒否され、部分的に生成された画像が削除されます。
- ChatGPT 内にはアップスケーリング機能はありません。
- モデルはトリミングに誤りがあり、生成された画像の一部のみを含む画像を出力する可能性があります。
- LLM に似た幻覚。
- 多くのコンセプトや個々の主題を含む画像を一度に生成するのは困難です。
- グラフ データを視覚化する画像の生成は正確ではありません。
- 画像内に非ラテン語のテキストを生成するのが難しい。
- タイプミスなど、画像生成の特定の部分を編集するリクエストは、常に有効であるとは限りません。
- モデルの命名: このモデルには、混乱を招く可能性がある複数の名前が付けられています: Imagegen、gpt-image-1、4o Image Generation、image\_gen.text2im…
- 場合によっては、プロンプトでの指定に関係なく、アスペクト比が間違っていることがあります。

### ヒントとベストプラクティス

<Callout type="info" emoji="⚙️">
**Use ChatGPT Personalization:**&#x53E4;い DALL-E 3 モデルへの切り替えを回避するには、設定の「ChatGPT に必要な特性」セクションに次の指示を追加します。

> 「DALL-E ツールは絶対に使用しないでください。常に新しい画像生成ツールを使用して画像を生成してください。画像ツールがタイムアウトになった場合は、DALL-E で生成する代わりに教えてください。」
</Callout>

- 生成制限に達した場合は、さらに画像を生成できるようになるまでの残り時間を ChatGPT に尋ねます。バックエンドには、ユーザーが利用できるこの情報が含まれています。
- 画像の生成と編集は、プロンプトで「描画」や「編集」などの明確な用語を使用すると最も効果的に機能します。
- 推論モデルを使用してイメージを生成すると、プロンプトの作成および改訂プロセスを通じてモデルがどのように推論するかを確認できるという追加の利点が得られます。思考トレースを開いて、モデルが何に焦点を当てているかを確認します。

### 試すユースケース

- **ロゴの生成:**&#x53C2;考画像と詳細な説明を使用してください。これは複数ターンにわたるタスクであることが多いため、推論モデルを使用してください。[チャットの例](https://chatgpt.com/share/6848aaa7-be7c-8007-ba6c-c69ec1eb9c25).
- **マーケティング資産の生成:**&#x65E2;存のビジュアル アセットを参照として使用し、モデルにテキスト、製品、環境の変更を促します。
- **塗り絵ページの生成:**&#x32;:3 のアスペクト比を使用して、カスタムの塗り絵ページを作成します。[チャットの例](https://chatgpt.com/share/684ac538-25c4-8007-861a-3fe682df47ab).
- **ステッカー画像:**&#x80CC;景が透明であることを忘れないでください。[チャットの例](https://chatgpt.com/share/684960b3-dc00-8007-bf16-adfae003dde5).
- **マテリアル転送:**&#x30DE;テリアルの参照画像を使用し、それを 2 番目の画像またはプロンプトから主題に適用します。[チャットの例](https://chatgpt.com/share/684ac8d5-e3f8-8007-9326-ea6291a891e3).
- **インテリアデザイン:**&#x90E8;屋の写真を撮り、特定の家具や機能の変更を促します。[チャットの例](https://chatgpt.com/share/684ac69f-6760-8007-83b9-2e8094e5ae31).
