信頼できる LLM は、医療や金融などのリスクの高い分野でアプリケーションを構築するために重要です。 ChatGPT のような LLM は人間が判読できる応答を生成する能力は非常に高いですが、真実性、安全性、プライバシーなどの側面にわたって信頼できる応答を保証するものではありません。

[Sun et al. (2024)](https://arxiv.org/abs/2401.05561)最近、LLM の信頼性に関する包括的な研究を提案し、課題、ベンチマーク、評価、アプローチの分析、および将来の方向性について議論しました。

現在の LLM を運用環境に導入する際の大きな課題の 1 つは、信頼性です。彼らの調査では、6 つの次元 (真実性、安全性、公平性、堅牢性、プライバシー、マシン倫理) にわたるベンチマークを含む、8 つの次元にわたる信頼できる LLM のための一連の原則が提案されています。

## 調査結果

この研究では、30 を超えるデータセットで構成される TrustLLM の 16 の主流 LLM を評価する研究も紹介します。評価の主な結果は以下のとおりです。

- プロプライエタリな LLM は一般に、信頼性の点でほとんどのオープンソースの対応物よりも優れていますが、その差を埋めつつあるオープンソース モデルがいくつかあります。
- GPT-4 や Llama 2 のようなモデルは、定型的なステートメントを確実に拒否し、敵対的な攻撃に対する回復力の強化を示します。
- Llama 2 のようなオープンソース モデルは、特別なモデレーション ツールを使用しなくても、信頼性に関して独自モデルに近いパフォーマンスを発揮します。また論文では、Llama 2などの一部のモデルは信頼性を重視して過度に調整されているため、いくつかのタスクでの実用性が損なわれ、無害なプロンプトが誤ってモデルへの有害な入力として扱われることも述べられています。

## 重要な洞察

この論文で調査されたさまざまな信頼性の側面について、報告された重要な洞察は次のとおりです。

- **真実性**: LLM は、トレーニング データのノイズ、誤った情報、または古い情報により、真実性を保つのに苦労することがよくあります。外部の知識ソースにアクセスできる LLM は、真実性のパフォーマンスが向上しています。

- **安全性**: オープンソース LLM は一般に、ジェイルブレイク、毒性、悪用などの安全性の面で独自のモデルに比べて遅れをとっています。過度に慎重になりすぎずに安全対策のバランスをとるのが課題です。

- **公平性**: ほとんどの LLM は、ステレオタイプの認識において満足のいくパフォーマンスを発揮しません。 GPT-4 のような高度なモデルでも、この領域の精度は約 65% しかありません。

- **堅牢性**: 特にオープンエンドタスクや配布外タスクでは、LLM の堅牢性には大きなばらつきがあります。

- **プライバシー**: LLM はプライバシー規範を認識していますが、個人情報の理解と取り扱いは大きく異なります。一例として、一部のモデルでは、Enron Email Dataset でテストしたときに情報漏洩が確認されています。

- **機械倫理**: LLM は道徳原則の基本的な理解を示します。しかし、複雑な倫理的シナリオでは不十分です。
