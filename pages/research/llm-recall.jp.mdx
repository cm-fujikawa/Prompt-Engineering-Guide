# LLM インコンテキストリコールはプロンプトに依存します

この新しい[Machlab と Battle による論文 (2024)](https://arxiv.org/abs/2404.08865)いくつかの干し草の中の針テストを使用して、さまざまな LLM のコンテキスト内再現パフォーマンスを分析します。

これは、さまざまな LLM がさまざまな長さと配置の深さでファクトを呼び出すことを示しています。その結果、モデルの再現パフォーマンスは、プロンプトの小さな変更によって大きく影響されることがわかりました。

!["Needle In the HayStack Performance"](../../img/research/haystack-performance.png)
*ソース：[マッハラボとバトル (2024)](https://arxiv.org/abs/2404.08865)*

さらに、プロンプト コンテンツとトレーニング データの間の相互作用により、応答の品質が低下する可能性があります。

モデルの再現能力は、サイズを大きくし、注意メカニズムを強化し、さまざまなトレーニング戦略を試し、微調整を適用することで改善できます。

この論文からの重要な実践的なヒント: 「継続的な評価により、個々のユースケースに応じた LLM の選択がさらに情報化され、テクノロジーが進化し続けるにつれて、現実世界のアプリケーションにおける LLM の影響と効率が最大化されます。」

このペーパーから得られることは、再現性と実用性を向上させるために、慎重なプロンプト設計、継続的な評価プロトコルの確立、さまざまなモデル拡張戦略のテストの重要性です。
