# Llama 3

import {Bleed} from 'nextra-theme-docs'

Meta recently [紹介された](https://llama.meta.com/llama3/)Llama 3 と呼ばれる大規模言語モデル (LLM) の新しいファミリーです。このリリースには、8B および 70B パラメーターの事前トレーニング済みモデルと命令調整済みモデルが含まれています。

## Llama 3 Architecture Details

Llama 3 について言及されている技術的な詳細の概要は次のとおりです。

- 標準のデコーダ専用トランスフォーマを使用します。
- 語彙は 128K トークンです。
- 8K トークンのシーケンスでトレーニングされます。
- グループ化されたクエリ アテンション (GQA) を適用します。
- 15T を超えるトークンで事前トレーニングされています。
- これには、SFT、拒絶サンプリング、PPO、DPO の組み合わせを含む事後トレーニングが含まれます。

## Llama 3 400B

Meta はまた、まだトレーニング中の 400B パラメーター モデルをリリースする予定であると報告しました。パイプラインでは、マルチモーダル サポート、多言語機能、およびより長いコンテキスト ウィンドウに関する取り組みも行われています。 Llama 3 400B の現在のチェックポイント (2024 年 4 月 15 日現在) は、MMLU や Big-Bench Hard などの一般的なベンチマークで次の結果を生成します。
