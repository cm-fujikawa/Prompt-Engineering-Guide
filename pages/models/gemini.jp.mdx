## Introduction to Gemini

Gemini は、Google Deepmind の最新の最も高性能な AI モデルです。マルチモーダル機能を最初から備えて構築されており、テキスト、画像、ビデオ、オーディオ、コードにわたる印象的なクロスモーダル推論を紹介できます。

Gemini には 3 つのサイズがあります。

- **ウルトラ**- モデル シリーズの中で最も高性能で、非常に複雑なタスクに適しています。
- **プロ**- 幅広いタスクにわたって拡張するための最良のモデルと考えられています
- **ナノ**- デバイス上のメモリに制約のあるタスクとユースケースのための効率的なモデル。これらには、大規模な Gemini モデルから抽出され、4 ビットに量子化された 1.8B (Nano-1) および 3.25B (Nano-2) パラメーター モデルが含まれています。

付属書によると[テクニカルレポート](https://storage.googleapis.com/deepmind-media/gemini/gemini_1_report.pdf), Gemini は、言語、コーディング、推論、マルチモーダル推論などのタスクをカバーする 32 ベンチマークのうち 30 で最先端の技術を進歩させています。

人間の専門家によるパフォーマンスを達成した最初のモデルです。[MMLU](https://paperswithcode.com/dataset/mmlu)(人気のある試験ベンチマーク)、20 のマルチモーダル ベンチマークで最先端の性能を発揮します。 Gemini Ultra は MMLU で 90.0%、[MMMU benchmark](https://mmmu-benchmark.github.io/)大学レベルの主題知識と推論が必要です。

Gemini モデルは、32k のコンテキスト長をサポートするようにトレーニングされ、効率的なアテンション メカニズムを備えた Transformer デコーダの最上位で構築されています (例:[マルチクエリの注意](https://arxiv.org/abs/1911.02150)）。オーディオおよびビジュアル入力とインターリーブされたテキスト入力をサポートし、テキストおよび画像出力を生成できます。

<Screenshot src={GEMINI2} alt="GEMINI2" />

モデルは、Web ドキュメント、書籍、コード データ (画像、音声、ビデオ データなど) などのマルチモーダル データと多言語データの両方でトレーニングされます。モデルはすべてのモダリティにわたって共同トレーニングされ、強力なクロスモーダル推論機能、さらには各ドメインでの強力な機能を示します。

## Gemini Experimental Results

Gemini Ultra は、次のようなアプローチと組み合わせることで最高の精度を実現します。[思考連鎖 (CoT) プロンプト](https://www.promptingguide.ai/techniques/cot)そして[Self-Consistency](https://www.promptingguide.ai/techniques/consistency)これはモデルの不確実性に対処するのに役立ちます。

テクニカル レポートで報告されているように、Gemini Ultra は、MMLU でのパフォーマンスを、グリーディ サンプリングの 84.0% から、32 個のサンプルを使用した不確実性ルート思考連鎖アプローチ (CoT と多数決を含む) を使用した 90.0% まで向上させますが、32 個の思考連鎖サンプルのみを使用した場合は 85.0% までわずかに向上します。同様に、CoT と自己無矛盾性は、GSM8K 小学生数学ベンチマークで 94.4% の精度を達成しています。さらに、Gemini Ultra は 74.4% を正しく実装しています。[HumanEval](https://paperswithcode.com/dataset/humaneval)コード補完の問題。以下は、Gemini の結果と、モデルが他の注目すべきモデルとどのように比較されるかをまとめた表です。

<Screenshot src={GEMINI3} alt="GEMINI3" />

Gemini Nano モデルは、事実 (検索関連タスク)、推論、STEM、コーディング、マルチモーダルおよび多言語タスクでも優れたパフォーマンスを示します。

標準的な多言語機能に加えて、Gemini は多言語の数学や要約ベンチマークでも優れたパフォーマンスを示します。[MGSM](https://paperswithcode.com/dataset/mgsm)そして[XLSum](https://paperswithcode.com/dataset/xl-sum)、 それぞれ。

Gemini モデルは 32K のシーケンス長でトレーニングされており、コンテキスト長全体でクエリを実行すると、98% の精度で正しい値を取得することがわかります。これは、ドキュメントの検索やビデオの理解などの新しいユースケースをサポートする重要な機能です。

命令に合わせて調整された Gemini モデルは、命令への従うこと、創造的な執筆、安全性などの重要な能力に関して人間の評価者によって一貫して好まれています。

## Gemini Multimodal Reasoning Capabilities

Gemini はネイティブにマルチモーダルにトレーニングされており、言語モデルの推論機能とモダリティ間の機能を組み合わせる能力を示します。機能には、表、チャート、図からの情報抽出が含まれますが、これらに限定されません。その他の興味深い機能には、入力からのきめ細かい詳細の識別、空間と時間にわたるコンテキストの集約、さまざまなモダリティにわたる情報の組み合わせなどがあります。

Gemini は、高レベルの物体認識、きめ細かい転写、チャートの理解、マルチモーダル推論などの画像理解タスク全体にわたって、既存のアプローチを常に上回っています。画像の理解および生成機能の一部は、多様なグローバル言語セットにも転送されます (例: ヒンディー語やルーマニア語などの言語を使用した画像説明の生成)。

### テキストの要約

Gemini はマルチモーダル システムとしてトレーニングされていますが、GPT-3.5、Claude、Llama などの最新の大規模言語モデルに存在する機能の多くを備えています。以下は、Gemini Pro を使用した単純なテキスト要約タスクの例です。私たちが使用しているのは[Google AI Studio](https://ai.google.dev)この例では温度値が 0 です。

Antibiotics are usually taken orally in the form of pills, capsules, or liquid solutions, or sometimes administered intravenously. They are not effective against viral infections, and using them inappropriately can lead to antibiotic resistance.

## Gemini での数回のプロンプト

フューショット プロンプトは、必要な出力の種類をモデルに示すのに役立つプロンプト アプローチです。これは、特定の形式 (JSON オブジェクトなど) やスタイルで出力する場合など、さまざまなシナリオで役立ちます。 Google AI Studio もインターフェースでこれを有効にします。以下は、Gemini モデルで少数ショット プロンプトを使用する方法の例です。

私たちは、Gemini を使用して単純な感情分類器を構築することに興味があります。最初のステップは、「新規作成」または「+」をクリックして「構造化プロンプト」を作成することです。数回のプロンプトでは、指示 (タスクの説明) と提供した例が結合されます。以下の図は、モデルに渡す命令 (上) と例を示しています。 INPUT テキストと OUTPUT テキストを設定して、よりわかりやすいインジケーターを付けることができます。以下の例では、「Text:」を入力として、「Emotion:」を入力インジケーターと出力インジケーターとしてそれぞれ使用しています。

## 図書館の利用状況

以下は、Gemini API を使用して Gemini Pro モデルをプロンプトする方法を示す簡単な例です。をインストールする必要があります`google-generativeai`ライブラリを作成し、Google AI Studio から API キーを取得します。以下の例は、上のセクションで使用したものと同じ情報抽出タスクを実行するコードです。

```python
"""
At the command line, only need to run once to install the package via pip:

$ pip install google-generativeai
"""

import google.generativeai as genai

genai.configure(api_key="YOUR_API_KEY")

# Set up the model
generation_config = {
  "temperature": 0,
  "top_p": 1,
  "top_k": 1,
  "max_output_tokens": 2048,
}

safety_settings = [
  {
    "category": "HARM_CATEGORY_HARASSMENT",
    "threshold": "BLOCK_MEDIUM_AND_ABOVE"
  },
  {
    "category": "HARM_CATEGORY_HATE_SPEECH",
    "threshold": "BLOCK_MEDIUM_AND_ABOVE"
  },
  {
    "category": "HARM_CATEGORY_SEXUALLY_EXPLICIT",
    "threshold": "BLOCK_MEDIUM_AND_ABOVE"
  },
  {
    "category": "HARM_CATEGORY_DANGEROUS_CONTENT",
    "threshold": "BLOCK_MEDIUM_AND_ABOVE"
  }
]

model = genai.GenerativeModel(model_name="gemini-pro",
                              generation_config=generation_config,
                              safety_settings=safety_settings)

prompt_parts = [
  "Your task is to extract model names from machine learning paper abstracts. Your response is an array of the model names in the format [\\\"model_name\\\"]. If you don't find model names in the abstract or you are not sure, return [\\\"NA\\\"]\n\nAbstract: Large Language Models (LLMs), such as ChatGPT and GPT-4, have revolutionized natural language processing research and demonstrated potential in Artificial General Intelligence (AGI). However, the expensive training and deployment of LLMs present challenges to transparent and open academic research. To address these issues, this project open-sources the Chinese LLaMA and Alpaca…",
]

response = model.generate_content(prompt_parts)
print(response.text)
```

出力は前と同じです。

```
[\"LLMs\", \"ChatGPT\", \"GPT-4\", \"Chinese LLaMA\", \"Alpaca\"]
```
