# Mistral Large

Mistral AI は、強力な多言語、推論、数学、コード生成機能を備えた最先端の大規模言語モデル (LLM) である Mistral をリリースします。 Mistral Large は、la Plataforme と呼ばれる Mistral プラットフォームと Microsoft Azure を通じて利用できます。新しいチャット アプリでテストすることもできます。[ル・シャ](https://chat.mistral.ai/).

以下は、Mistral Large が GPT-4 や Gemini Pro などの他の強力な LLM とどのように比較されるかを示すグラフです。 MMLU ベンチマークでは 81.2% のスコアで GPT-4 に次いで 2 位にランクされています。

!["Mistral Large Performance"](../../img/mistral-l/ml-performance.png)

## Mistral Large Capabilities

ミストラル ラージの機能と強みは次のとおりです。

- 32K tokens context window
- ネイティブの多言語能力を持っている（英語、フランス語、スペイン語、ドイツ語、イタリア語に堪能）
- 推論、知識、数学、コーディングベンチマークにおける強力な能力
- 関数呼び出しと JSON 形式がネイティブにサポートされています
- Mistral Smallという低遅延モデルもリリースされました
- 開発者は正確な指示に従ってモデレーション ポリシーを設計できます。

## Mistral Small

Mistral Large のリリースに加えて、Mistral Small と呼ばれる小型モデルと最適化されたモデルも発表されました。 Mistral Small は、低レイテンシーのワークロード向けに最適化されており、Mistral 8x7B よりも優れたパフォーマンスを発揮します。 Mistral AI は、このモデルが RAG 対応、関数呼び出し、JSON 形式に関して強力な機能を備えていると報告しています。
