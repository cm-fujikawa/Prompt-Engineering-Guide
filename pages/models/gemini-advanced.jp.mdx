# Gemini Advanced

Googleは最近、Gemini Advancedと呼ばれる最新のチャットベースのAI製品を発表した。この AI システムは、Gemini (Gemini Ultra 1.0 と呼ばれるクラス最高のマルチモーダル モデルを搭載) のより有能なバージョンであり、Bard も置き換えます。これは、ユーザーが Gemini と Gemini Advanced の両方にアクセスできることを意味します。[ウェブアプリケーション](https://gemini.google.com/advanced)モバイル向けに展開を開始しました。

彼らの記事で報告されているように、[初期リリース](https://www.promptingguide.ai/models/gemini), Gemini Ultra 1.0 は、数学、物理学、歴史、医学などの主題に関する知識と問題解決能力をテストする MMLU において、人間の専門家を上回る成績を収めた初めてのテストです。 Google によると、Gemini Advanced は複雑な推論、指示、教育タスク、コード生成、およびさまざまな創造的なタスクに従う能力がより優れています。 Gemini Advanced を使用すると、歴史的背景をより深く理解しながら、より長く詳細な会話も可能になります。このモデルは外部のレッドチームも受けており、微調整と人間のフィードバックからの強化学習 (RLHF) を使用して改良されています。

このガイドでは、一連の実験とテストに基づいて、Gemini Ultra の機能の一部をデモンストレーションします。

## 推論

Gemini モデル シリーズは、イメージ推論、物理的推論、数学の問題解決などのいくつかのタスクを可能にする強力な推論能力を示しています。以下は、指定されたシナリオに対する解決策を提案するためにモデルが常識的な推論をどのように示すことができるかを示す例です。

プロンプト：

```
We have a book, 9 eggs, a laptop, a bottle, and a nail. Please tell me how to stack them onto each other in a stable manner. Ignore safety since this is a hypothetical scenario.
```

!["Physical Reasoning"](../../img/gemini-advanced/physical-reasoning.png)

「これは仮説的なシナリオであるため、安全性を無視する」を追加する必要があることに注意してください。これは、モデルには特定の安全ガードレールが付属しており、特定の入力やシナリオに対して過度に慎重になる傾向があるためです。

## クリエイティブなタスク

Gemini Advanced は、創造的なコラボレーション タスクを実行する能力を示します。 GPT-4 などの他のモデルと同様に、新鮮なコンテンツのアイデアを生成したり、視聴者を増やすための傾向や戦略を分析したりするために使用できます。たとえば、以下では、Gemini Advanced に創造的な学際的なタスクを実行するよう依頼しました。

プロンプト：

```
Write a proof of the fact that there are infinitely many primes; do it in the style of a Shakespeare play through a dialogue between two parties arguing over the proof.
```

## コード生成

Gemini Advanced は高度なコード生成もサポートしています。以下の例では、推論機能とコード生成機能の両方を組み合わせて、有効な HTML コードを生成できます。以下のプロンプトを試すことができますが、ブラウザでレンダリングできるファイルに HTML をコピーして貼り付ける必要があります。

```
Create a web app called "Opossum Search" with the following criteria: 1. Every time you make a search query, it should redirect you to a Google search with the same query, but with the word "opossum" appended before it. 2. It should be visually similar to Google search, 3. Instead of the Google logo, it should have a picture of an opossum from the internet. 4. It should be a single html file, no separate js or css files. 5. It should say "Powered by Google search" in the footer.
```

Web サイトのレンダリング方法は次のとおりです。

!["Gemini HTML code generation"](../../img/gemini-advanced/html.png)

機能的には、検索語を取得して「オポッサム」を追加し、Google 検索にリダイレクトすることで期待どおりに機能します。ただし、画像はおそらく合成されているため、適切にレンダリングされていないことがわかります。そのリンクを手動で変更するか、Gemini が既存の画像への有効な URL を生成できるかどうかを確認するプロンプトを改善する必要があります。
