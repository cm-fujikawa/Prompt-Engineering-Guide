# Claude 3

Anthropic は、Claude 3 Haiku、Claude 3 Sonnet、Claude 3 Opus を含む新しいモデル ファミリである Claude 3 を発表しました。

Claude 3 Opus (最も強力なモデル) は、MMLU や HumanEval などの一般的なベンチマークで GPT-4 や他のすべてのモデルよりも優れたパフォーマンスを発揮すると報告されています。

## 実績と能力

Claude 3 の機能には、高度な推論、基本的な数学、分析、データ抽出、予測、コンテンツ作成、コード生成、およびスペイン語、日本語、フランス語などの英語以外の言語への変換が含まれます。以下の表は、いくつかのベンチマークで Claude 3 が他のモデルとどのように比較されているかを示しており、Claude 3 Opus は言及されているすべてのモデルを上回っています。

!["Claude 3 Benchmarks"](../../img/claude/claude-benchmark.png)

Claude 3 Haiku は、シリーズの中で最も高速かつ最もコスト効率の高いモデルです。 Claude 3 Sonnet は、以前の Claude のイテレーションより 2 倍高速で、Opus は、より優れた機能を備えた Claude 2.1 と同じくらい高速です。

Claude 3 モデルは 200K コンテキスト ウィンドウのサポートを提供しますが、一部の顧客向けに 100 万トークンまで拡張できます。 Claude 3 Opus は、大規模なコーパス内の情報を想起し、長いコンテキスト プロンプトを効果的に処理するモデルの能力を測定する Needle In A Haystack (NIAH) 評価で、ほぼ完璧な再現率を達成しました。

このモデルは、写真、チャート、グラフなどの形式を処理するための強力なビジョン機能も備えています。

!["Claude 3 Vision Capabilities"](../../img/claude/claude-vision.png)

Anthropic はまた、これらのモデルは要求をより微妙に理解しており、拒否が少ないと主張しています。また、Opus は、不正解や幻覚を減らしながら、自由回答形式の質問における事実に基づく質問の回答が大幅に向上していることを示しています。 Claude 3 モデルは、JSON オブジェクトのような構造化された出力を生成する点でも、Claude 2 モデルよりも優れています。
